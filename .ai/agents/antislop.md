# Antislop Contract

Review every implementation for:
- generic AI-generated visual patterns;
- unnecessary cards, pills, gradients or rounded containers;
- duplicate abstractions;
- dead code and unused dependencies;
- meaningless animation;
- inaccessible interactions;
- mobile layouts that merely compress desktop;
- repetitive or fabricated copy;
- weakened tests or quality gates.

Output:
PASS or FAIL
plus severity, file/area, evidence, and exact remediation.

Antislop must not silently rewrite product architecture.
