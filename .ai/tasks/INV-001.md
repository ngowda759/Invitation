# INV-001 — Initialize Application Foundation

Phase: P1 Foundation
Status: first and only implementation task

## Objective

Establish the production-ready application foundation for the Invitation project so
that later phases can build the invitation experience on a clean, tested, CI-backed base.

## Scope

1. Next.js (latest stable) App Router with TypeScript.
2. Tailwind CSS foundation and a minimal shadcn/ui foundation (`cn`, `Button`).
3. Clean project structure (`src/app`, `src/components`, `src/content`, `src/lib`, `tests`).
4. ESLint configuration.
5. Vitest unit/component tests.
6. Playwright end-to-end configuration with a smoke test.
7. Responsive, mobile-first base layout.
8. Metadata and SEO foundation.
9. GitHub CI: `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.

## Explicitly out of scope

- Database
- Authentication
- Raya AI
- Rayaramathaynk runtime APIs
- Hero animation
- Fabricated temple facts (dates, timings, historical or religious claims)

## Acceptance criteria

- `npm ci` succeeds.
- `npm run lint` succeeds.
- `npm run typecheck` succeeds.
- `npm test` succeeds.
- `npm run build` succeeds.
- `npm run test:e2e` smoke test succeeds.
- The base layout is responsive and mobile-first.
- Metadata and SEO foundation are present.
- CI runs the five required steps with `permissions: contents: read`.
- No database, no authentication, no Raya AI, no Rayaramathaynk runtime dependency.
- No hero animation and no fabricated temple facts.

## Validation evidence required

- Commands run and their results.
- Files changed.
- Known limitations and the recommended next task.
