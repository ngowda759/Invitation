# INV-P1-001 — Initialize Application Foundation

## Objective
Create the production foundation for Rayara Anubhava without implementing the visual invitation experience yet.

## Scope
1. Initialize Next.js App Router + TypeScript.
2. Add Tailwind CSS and minimal shadcn/ui foundation.
3. Establish the architecture documented in `docs/ARCHITECTURE.md`.
4. Add linting/formatting.
5. Add Vitest and Playwright foundations.
6. Add responsive root layout and metadata foundation.
7. Add GitHub CI for install, lint, typecheck, tests and build.
8. Keep the implementation static-first.

## Explicitly out of scope
- Event-specific fabricated content
- Database/authentication
- Rayaramathaynk APIs
- Raya AI/chatbot
- Payments
- Realtime backend
- Full hero/animation implementation
- Unnecessary dependencies

## Acceptance criteria
- `npm install` succeeds.
- lint succeeds.
- typecheck succeeds.
- unit tests succeed.
- production build succeeds.
- CI is green.
- Mobile-first structure exists.
- No invented temple-specific facts.
- No direct dependency on Rayaramathaynk.

## Handoff
OpenHands must report changed files, checks run, failures, limitations and recommended next task.
