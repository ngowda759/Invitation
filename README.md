# Rayara Anubhava — Digital Temple Invitation

An immersive, mobile-first digital temple invitation experience for Sri Raghavendra Swamy Mutt, Yelahanka New Town, Bengaluru.

## Project boundary

This repository is part of the temple-web ecosystem conceptually, but is a **separate codebase** from `Rayaramathaynk`.

It must **not** be pulled into or modified by the Rayaramathaynk AI development loop.

## Autonomous delivery system

- **ChatGPT** — product authority, architecture, UX, visual design, specifications, acceptance criteria, and final quality authority.
- **Paperclip** — orchestration, phase management, task routing, dependency handling, retries, and state.
- **OpenHands** — implementation, tests, debugging, and refactoring.
- **Antislop** — anti-pattern, code-quality, UI-quality, and generated-slop gate.
- **GitHub** — source of truth for code, issues, pull requests, CI, and release history.

## Current status

Application implementation starts only after the constitution is accepted.
