# Delivery Phases

## Phase 0 — Constitution
Deliver:
- project docs
- agent contracts
- quality gates
- CI skeleton
- content model
- design tokens

Gate: architecture/design approved.

## Phase 1 — Foundation
Deliver:
- Next.js app
- TypeScript
- Tailwind
- shadcn/ui baseline
- lint/typecheck/test/build
- base layout
- metadata foundation

Gate: clean CI.

## Phase 2 — Visual System
Deliver:
- typography
- colors
- spacing
- motion primitives
- ornaments
- buttons/cards
- responsive foundations

Gate: design review.

## Phase 3 — Opening + Hero
Deliver:
- opening experience
- invocation
- temple hero
- event identity
- primary CTAs

Gate: visual review on mobile + desktop.

## Phase 4 — Invitation Content
Deliver:
- Darshan
- festival
- programme timeline
- Guru Rayaru
- Seva sections

Gate: content and interaction review.

## Phase 5 — Temple Experience
Deliver:
- temple map
- gallery
- location
- sharing

Gate: end-to-end invitation journey.

## Phase 6 — Mobile / Accessibility
Deliver:
- mobile polish
- keyboard navigation
- focus states
- reduced motion
- semantic structure
- screen-reader sanity checks

Gate: accessibility checklist.

## Phase 7 — Performance
Targets:
- LCP < 2.5s on representative mobile conditions
- CLS < 0.1
- INP < 200ms where measurable
- optimized image payloads
- no unnecessary client components

Gate: performance report.

## Phase 8 — Security / Hardening
Check:
- secrets
- dependency vulnerabilities
- unsafe HTML
- external links
- security headers
- CSP compatibility
- content injection risks

Gate: security pass.

## Phase 9 — Antislop
Check:
- duplicate components
- dead code
- unnecessary abstractions
- generic AI-looking copy/UI
- excessive animation
- excessive cards
- unnecessary dependencies
- inconsistent spacing/typography

Gate: Antislop pass.

## Phase 10 — Release
Run:
- unit tests
- e2e tests
- lint
- typecheck
- build
- performance
- security
- Antislop
- final ChatGPT review

Only then release/deploy.

## Phase 11 — Devotional Invitation Experience
Deliver:
- invitation cover reveal
- devotional opening composition
- temple-atmosphere storytelling
- ceremonial programme typography
- warm people/family presentation
- ornament vocabulary
- restrained ceremonial motion
- mobile-first invitation rhythm

Gate: invitation experience review on mobile + desktop.
