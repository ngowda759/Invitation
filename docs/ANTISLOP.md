# Antislop Quality Contract

Antislop is a mandatory quality gate.

## Detect
- generic AI-generated visual patterns
- repetitive cards
- meaningless gradients
- excessive rounded containers
- unnecessary wrappers
- duplicate utility classes
- dead code
- unused dependencies
- excessive abstraction
- repetitive copy
- fake complexity
- gratuitous animation
- inconsistent spacing
- inaccessible interactions

## UI quality questions
- Does every element have a purpose?
- Does hierarchy feel intentional?
- Is the visual language coherent?
- Does mobile feel designed rather than compressed?
- Are animations helping rather than distracting?

## Result
PASS — no blocking issues.

FAIL — produce actionable findings with severity and expected fix.
