# OpenHands Implementation Contract

OpenHands is the primary implementation agent.

## Before coding
1. Read README and docs.
2. Identify current phase.
3. Inspect existing repository state.
4. Make the smallest coherent implementation.
5. Add/update tests.
6. Run required checks.

## During coding
- Prefer simple code.
- Avoid speculative abstractions.
- Keep client-side JavaScript minimal.
- Optimize images and fonts.
- Keep components accessible.
- Respect the design system.

## Completion report
Return:
- implementation summary
- files changed
- tests
- lint
- typecheck
- build
- screenshots/evidence when visual
- known limitations
